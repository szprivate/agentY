# Video tutorials

Seven short videos (about a minute each) that show agentY's main features on screen.
Click a picture to play the video. For the full written guide see [Using agentY](using-agentY.md).

| | |
|---|---|
| [![Install](images/tutorials/tut01_install.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut01_install.mp4) | **1 · Install** (1:00)<br>Clone the `stable` branch, run the installer, pick LLM providers, the execution mode and MCP presets, start agentY, and find the agentY tab in ComfyUI's sidebar. See also [Installation](../README.md#installation). |
| [![Side panel and settings](images/tutorials/tut02_panel_settings.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut02_panel_settings.mp4) | **2 · The chat panel and Settings** (1:22)<br>Conversations, undo, the prompt loop, `/` commands, attaching images, choosing the model per role or tier, agentY hooks (full run and dry run), then Settings: models, MCP servers from presets, execution mode, Slack and pricing. See also [The chat panel](using-agentY.md#the-chat-panel) and [Settings & secrets](using-agentY.md#settings--secrets). |
| [![Tags and hooks](images/tutorials/tut03_hooks.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut03_hooks.mp4) | **3 · Tags, hooks, loops and reviews** (1:19)<br>Tag a reference with `agentY add tag` or from the viewer, use it with `#` in a hook prompt, chain hook stages on the execution wire, repeat stages in a loop until a condition holds, and pick what continues at a review stop in the bEpic viewer. See also [The hook system](using-agentY.md#the-hook-system). |
| [![Atlas](images/tutorials/tut04_atlas.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut04_atlas.mp4) | **4 · World Labs Atlas** (0:59)<br>Ask agentY for a world from one picture, orbit and fly through it in the viewer (Shift+J, W A S D), paint the view you are looking through with **Render with Atlas** and add it to the world, and keyframe a camera move through it. See also [worldlabs_atlas.md](integrations/worldlabs_atlas.md). |
| [![Motion panel](images/tutorials/tut05_motion.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut05_motion.mp4) | **5 · Motion graphics** (1:25)<br>Ask agentY for a title card, then edit it in the viewer's Motion tab: layers, keyframes, curves, on-canvas move / scale / rotate / anchor, text. Save, Render, and reopen it from its poster PNG with **Edit in Motion**. |
| [![Gaussian splats](images/tutorials/tut06_splats.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut06_splats.mp4) | **6 · Gaussian splats** (0:54)<br>Ask agentY to train a splat from an Atlas world (locally with Brush, no credits), step through the training previews, open and orbit the splat in the viewer, render a camera move through it, and use the standard `.ply` elsewhere. |
| [![LoRA training](images/tutorials/tut07_lora.jpg)](https://github.com/szprivate/agentY/releases/download/v1.8.0/tut07_lora.mp4) | **7 · LoRA training** (0:55)<br>Ask agentY to prepare a dataset, review and edit it in the viewer's Dataset panel (captions, include / exclude), press **Approve & train**, watch steps, loss and samples in the Training tab, and find the LoRA in `loras/agentY/`. |
