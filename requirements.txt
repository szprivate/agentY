# ── QA likeness: is this the same person / the same subject? ────────────────
# The `agentY qa briefing` node's `likeness` control (src/utils/likeness.py).
# "Same character" is the criterion people write most often and the one a vision
# model answers worst, so it is measured instead of judged.
#
#   * insightface + onnxruntime — ArcFace face embeddings, compared by cosine.
#     On this machine's own renders the same character scores 0.95-0.98 and
#     different characters 0.09-0.54, including on stylised faces.
#   * dreamsim — perceptual similarity for everything that is not a face (a
#     location, a product, a grade). Trained on human judgements of DIFFUSION-
#     generated triplets, so its notion of "alike" is fitted to these pictures.
#     It pulls transformers / open_clip_torch / peft / accelerate with it.
#
# Both are imported lazily and only when the control is set: DreamSim's first
# load is ~100 s, the two together download ~3.6 GB of weights, and a QA pass
# with no reference to compare against must not pay any of it. Weights land in
# <agentY>/models (gitignored), NOT in the user's profile, so the drive they
# occupy is a decision rather than a default. Both run on the CPU by design —
# the GPU belongs to ComfyUI, and a QA pass that fights the render it is judging
# is a bad trade at any accuracy. Without these, likeness falls back to the
# written criterion and the vision model's opinion.
insightface>=0.7.3
onnxruntime>=1.18
dreamsim>=0.2.1

# ── Image annotation: locating what to mark ─────────────────────────────────
# SAM 3 turns a text prompt into boxes + masks, so "circle the bolts" resolves
# in-process — no round-trip through a ComfyUI graph, which is what lets
# annotation still work while ComfyUI is down.
#
# This is Meta's own package, NOT the ComfyUI-SAM3 node's vendored copy: that one
# imports comfy.ops and comfy.ldm.modules.attention across six modules and cannot
# be used outside ComfyUI.
#
# It reuses the checkpoint ComfyUI already has — models/sam3/sam3.safetensors from
# the ungated apozz/sam3-safetensors mirror — so there is nothing to download and
# no need for the gated facebook/sam3 repo. Two things about that file: it is the
# unified VIDEO model, with the image model under a "detector." key prefix (strip
# it and all 1134 image-model keys are covered), and upstream's own loader is
# torch.load, i.e. a .pt pickle, so agentY reads the safetensors itself.
#

# backend and annotation falls back to the vision model.
